# PsychoNova

**AI-Powered Mental Health Companion for Students**  
Built for Innovyuh 2.0 Hackathon at MIT Arts, Commerce and Science College, Pune

### 🎯 Live Prototype (MVP)
https://mind-nova-path.base44.app/

### ✨ Key Features
- Google Login + Unique Nova Name
- Psycho Lens (AI reads your handwriting, doodles & thoughts)
- Mood Tracker
- Video Call with Real Counselors
- Anonymous Student Community
- Nearest Help Map

### Tech Used
- Built with Base44 (AI app builder)
- Powered by Google Gemini (Psycho Lens simulation)


Made with ❤️ for students struggling with stress, anxiety & overthinking.
